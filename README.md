# Befit - Hospital & Physiotherapy Management System

## Overview
Befit is a comprehensive full-stack hospital and physiotherapy management system designed to streamline patient operations, billing, and clinic administration. It provides a secure, role-based platform for managing patient records, tracking treatment progress, and handling administrative tasks efficiently.

## Core Features
* **Secure Authentication & Authorization:** Robust role-based access control (RBAC) powered by Spring Security to manage clinic staff and administrative access.
* **Patient Management:** Complete CRUD endpoints to handle patient profiles, medical histories, and ongoing physiotherapy treatment plans.
* **Billing & Invoicing:** Integrated billing modules with seamless frontend receipt printing interfaces for patient transactions.
* **Responsive Dashboard:** Modern, intuitive UI built with React and styled with Tailwind CSS for optimal performance across devices.

## Tech Stack
